# 验收规格：指标定义与门禁流程

> 分阶段执行时，G1/G2 每阶段必跑，G5 按阶段清单核对，G6/G7 仅批次终验执行——
> 阶段划分与时间盒见 `docs/six-hour-execution-plan.md`。

> 版本：2026-09-08。适用：残留清零攻坚各批次及后续所有 parity 轮次。
> 执行工具：`evtx-parity-test/scripts/acceptance-check.py`（本规格的机器可执行形态，
> 退出码 0/1 可接 CI 或 jj hook）。

## 1. 指标定义（M1–M6）

| # | 指标 | 公式 | 数据源 | 目标 | 当前实测 |
|---|---|---|---|---|---|
| M1 | 主线匹配率 | matched ÷ compared | report.json | ≥97.53%（理想线 97.59%） | **97.5641%**（32002/32801） |
| M2 | D 闭环率（硬门） | 1 − D残留 ÷ 348 | report.json categories | 硬门 ≥80%；本轮批准 86% | **91.38%**（30/348） |
| M3 | 簇闭环 | 目标簇条数 → 0 | report.diff 分簇 | 批次清单逐簇核对 | 见批次报告 |
| M4 | 豁免命中数 | 白名单键命中条数 | report.diff × 登记表 | = 登记表条数（每条恰一次） | 7 项 / 26 条 |
| M5 | 有效分歧 | diff − 豁免命中 | 同上 | 轮间单调下降 | ≈773（799−26） |
| M6 | 回归红线 | 见 §2 G2 | report.json | 全部布尔成立 | 全过 |

**matched 的精确定义**（比对口径，06-compare.py 实现）：同一通道按出现顺序逐条对齐；
EventID / Provider / Channel 完全相等；TimeCreated 两边本地时间容差 2s；Message 经
`canon_msg`（`;`→空格、空白归一）+ `norm_msg_time_frac`（时间小数截 6 位）后完全相等。
豁免命中在比对后按簇扣减，不改写比对本身。

## 2. 门禁流程（G1–G7，顺序执行）

| 门 | 内容 | 程序 | 通过标准 | 失败处置 |
|---|---|---|---|---|
| **G1** | 指标门 | `acceptance-check.py` | M1 ≥ 下限；M2 ≥ 硬门 80% | 未达 → 缺口簇清单披露（G4），不得静默；连续两轮未达 → 计划变更 |
| **G2** | 回归红线门（一票否决） | 同上（需 `--prev` 上轮基线） | Security/Setup diff=0；各通道 B/C 不新增；无"缺失"类 diff | 立即 `jj` 回退至上一个绿提交复跑确认；再逐提交重放二分定位 |
| **G3** | 豁免核对门 | 同上 + 登记表 | 命中数与登记表一致；M5 单调下降 | 命中数异常增长 → 豁免条目发生变化 → 人工复核根因 |
| **G4** | 理想线披露 | 同上 | 无硬性判定，强制披露缺口 | — |
| **G5** | 簇核对门 | report.diff 分簇清单 | 批次目标簇逐簇归零；新簇数 ≤ 上轮 | 未归零簇写明原因（转豁免/转 research/缺陷） |
| **G6** | 关豁免复核门 | `--no-exemptions` 口径全量复跑 | 关豁免后无**意外**分歧被掩盖 | 有 → 豁免登记与实际分歧不符 → 修登记 |
| **G7** | 文档与提交门 | 人工核对单 | 单测绿、红线复核结论、skill 三镜像同步、STATUS/计划文档更新 | 缺项不提交 |

**执行顺序**：每轮迭代依次过 G1→G7；G6 仅在批次验收时执行（常规轮跳过）。
脚本会自动 SKIP 无前置数据的门（如未提供 `--prev` 时的 B/C 对比）。

## 3. 豁免生命周期（ADR 0006 细则）

```
登记（根因码 PARSE/SRC/BIN/RO + 关闭条件）
  → 白名单/归一实施（EXEMPTIONS 表 + canon 规则）
  → 每轮 G3 命中核对（数量漂移 = 人工复核信号）
  → 关闭条件满足 → 摘出转修复 → 移除白名单 → 全量复跑
```

- 登记表唯一真源：`docs/residual-zeroing-plan-2026-09-07.md` §4；
  脚本内 `EXEMPTIONS` 表必须与之同步（两处改动须同一提交）。
- **条件性豁免**（如 6013 SRC）在 research 退出前保持"登记未命中"或"命中"状态均可，
  但转正/摘除必须变更登记表并注明日期。


## 5. 工具用法

```bash
cd evtx-parity-test
cp report.json report.prev.json        # 上轮基线快照（迭代前做）
python scripts/acceptance-check.py --prev report.prev.json     # 常规验收
python scripts/acceptance-check.py --no-exemptions             # G6 关豁免口径
echo $?   # 0=必过门全过；1=有 FAIL
```
